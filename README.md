# task-complete-notify

Desktop notification + chime when AI agent finishes a task.

This repo contains two packages:

| Directory | Platform | Registry | Install |
|-----------|----------|----------|---------|
| `pi-extension/` | Pi Coding Agent | npm | `pi install npm:task-complete-notify` |
| `openclaw-plugin/` | OpenClaw | ClawHub | `openclaw plugins install clawhub:task-complete-notify` |
