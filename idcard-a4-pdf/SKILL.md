# idcard-a4-pdf — 证件照片裁切 + 透视校正 + A4 PDF（可自动命名）

把证件照片处理成干净的证件图（去背景、拉正透视、裁暗框）并排版到一张 A4，导出 PDF，可选自动按持证人姓名命名。全部本地处理，不依赖视觉模型。

## 快速开始

```bash
python3 ~/.dsh/skills/idcard-a4-pdf/scripts/idcard_crop.py <输出.pdf> <正面图> [背面图] [--export-png] [--auto-name]
```

- 支持 1~2 张图：1 张居中排版，2 张**上下排列**（第一张在上=正面、第二张在下=背面）
- `--auto-name`：从正面卡片 OCR 提取姓名，输出命名为 `<姓名>身份证.pdf`（如 `刘晓鹏身份证.pdf`）
- `--name 姓名`：显式指定姓名（**视觉模型读出的姓名传这里，比 OCR 更可靠**）
- `--export-png`：额外导出每张裁切后的证件 PNG；`--dpi`：默认 300
- 默认自动裁掉卡片四周深色边框（扫描/裁切残留），`--no-trim-frame` 可关闭

## 输出与行为

- PDF 为 A4 单页，卡片按真实证件尺寸（85.6×54mm）排版，带浅灰描边
- 两张图时**上下排列**（第一张在上=正面、第二张在下=背面）；一张图时居中
- **单图多卡**：一张图里同时含正反面（上下/左右排列）也能识别并自动拆分为正/背面
- 默认自动裁掉卡片四周深色边框（`--no-trim-frame` 关闭）
- 脚本打印每张图的诊断：候选 bbox、纵横比、四角、边长、往返验证置信度（% 像素一致）、暗框裁切量、识别到的姓名

## 检测鲁棒性（实测矩阵）

| 输入类型 | 结果 |
|---|---|
| 手机拍摄（冷色卡/暖色桌、透视畸变） | ✅ 检出 + 透视校正 |
| 已裁切扫描件（带深色暗框） | ✅ 检出 + 自动裁框 |
| 白底网页模板（蓝调卡面，单图双卡） | ✅ 检出两张并拆分 |
| **卡片竖拍/横竖颠倒** | ✅ 自动旋转校正（±90° 竞争） |
| **手机照片带 EXIF 方向标签** | ✅ 自动转正 |
| **暖色物体粘连/覆盖卡片** | ✅ 边缘异物检测拦截（蓝+暖双向） |
| 无卡片图片 | ✅ 干净失败并给建议 |

防误检机制：候选按「纵横比≈1.585 + 矩形填充率 + 位于图内 + 面积」打分；整图当卡（纵横比 <0.9）被拒绝；卡片内部小碎块（面积 <0.5%）与桌面污渍（最小边长 <90px）被剔除；大候选内的包含块视为内部特征；第二张卡需面积 ≥25% 且比例接近标准证（防阴影/碎块冒充）；旋转竞争仅在「首遍失败」或「竖图且候选贴住 ≥3 条边」（疑似旋转整卡的切片）时启动。

## 姓名提取（--auto-name）说明

- 原理：二代证正面"姓名"值位于卡片固定相对位置 → 模板区域 OCR（psm7/psm6 双模式一致才采信）
- **第一张图必须是正面**（姓名只从第一张图提取）
- 适合**标准二代证版式**；非标准版式（如网页模板）自动命名会安全放弃（回退默认文件名），此时用视觉模型读姓名后传 `--name`
- 局限：本地 tesseract 对个别字形（如 倩/倾）可能读错 1 个字；需要精确姓名时用 `--name` 显式指定
- 背面图不会误识别（标题字样黑名单过滤）

## 边界情况（把脚本诊断转述给用户）

- **检测失败 / 置信度低（得分 <0.45 或验证 <80%）**：背景有超大冷色（蓝/绿）物体、卡片被遮挡、卡片边缘与背景同色。建议用户重拍：卡片完整入镜、背景无大块蓝绿色物体
- **背景杂乱**：脚本会枚举所有候选连通块，按「纵横比≈1.585 + 矩形填充率 + 位于图内 + 面积」打分选最像卡片的，不会被最大的冷色物体带偏
- **卡片与冷色物体粘连/覆盖**：校正后输出边缘若检测到 >1% 强饱和蓝/绿像素，该图会被排除并报错，不纳入 PDF（避免混入异物）——此时建议重拍
- **非身份证（比例不同）**：仍按检测结果输出，纵横比先验会自动放宽
- **已裁切扫描件带深色边框**：自动裁掉（默认开启）

## 注意

- 产物含敏感个人信息（姓名、证件号等），只保存到用户指定本地路径，并提醒用户勿外传
- 依赖 PIL + tesseract（chi_sim）：`python3 -m pip install pillow`；tesseract 缺失时 `--auto-name` 自动降级为默认文件名
